Studio as a conversation

Generation becomes a chat thread, like Claude. You describe a creative, the assistant replies with generated variations inside the conversation. Type again and the next creative continues in the same thread — keeping context, not starting over. A + New chat button and a left conversation list let you jump between sessions. The 3 tabs (Custom · Top Ads · Ad Library) stay; “Custom” is now this chat.

Design spec

  • Thread: user prompts as right-aligned bubbles, AI replies with inline creative cards.
  • Continuation: follow-ups refine in the same thread; assistant keeps prior context.
  • New chat: top of the conversation rail (desktop) / drawer (mobile); resets to empty state.
  • Conversation list: grouped Today / Yesterday / Previous 7 days; searchable; rename + delete on hover.
  • Composer: ＋ attach (image / video / Top-Ad reference), Direct-mode chip, send. Sticky at bottom.
  • Per-creative actions: Save to Saved, Download, Variations, Use as source.
  • Tabs preserved: Custom (chat) · Top Ads · Ad Library. History rolls into the conversation list.
