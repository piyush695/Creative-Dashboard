Merging “Custom” + “Studio” into one focused workspace

The old Custom and Studio tabs collapse into a single Custom workspace. Source assets (the former Studio job) are no longer a separate tab — they are added inline through a single + Create action. The section now exposes just three tabs: Custom · Top Ads · Ad Library. Layout is Claude-inspired: one clear input column, one large result canvas, minimal chrome, content-first.

Design spec

  • Tabs: Custom · Top Ads · Ad Library (segmented control, blue active pill).
  • + Create: dropdown on desktop, bottom sheet on mobile. Opens on click and hover (desktop).
  • Menu items: Upload image, Upload video, Add content, Import from URL, Use a Top Ad as reference.
  • Source assets: thumbnails with remove + reorder, replacing the old “Studio” source panel.
  • Direct mode: unchanged toggle, kept on the Custom tab.
  • Generate + History + Saved: all preserved — nothing is removed functionally.
