Design spec & migrationwhat changed from v1 and how today’s pieces map

What changed in v2

  • Second rail removed — recent chats now live in the single left Studio sidebar (New chat → search → titled list).
  • Dedicated History page — every conversation as a card with title, date, creative count, saved badge, thumbnail strip, and “Open chat”.
  • Chat search — quick search in the sidebar (titles) and full search in History (titles + prompts).
  • Titled chat list — clear names, date-grouped, active highlighted; hover for rename / delete.
  • Full-width conversation — main area is just the thread + composer; cleaner and more focused.

Mapping

  • Custom/Studio prompt → composer · results → inline in thread · ＋ Create → composer ＋ attach.
  • History (old button) → both the sidebar chat list and the dedicated History page.
  • Top Ads · Ad Library · Saved · Direct mode → unchanged.
